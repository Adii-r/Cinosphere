# 🎬 Cinosphere

### Overview

Cinosphere is a full stack cinema management system built using **Java Servlets, JSP, and MySQL**, designed to streamline cinema operations while providing a seamless booking experience for end users. This system combines **role based access control, secure authentication, administrative management, and relational database operations** into a unified platform.

## ✨ Features

### 🎟️ User Booking

* Browse available movies and cinema offerings
* Seamless movie booking workflow
* User specific booking management
* Session based authentication and route protection

### 🔐 Authentication & Security

* Secure user authentication
* Session management for active login states
* Protected user and administrative routes
* Role Based Access Control (RBAC)

### 🛠️ Admin Dashboard

* Dedicated administrative dashboard
* Manage users and cinema data
* Monitor and manage booking-related operations
* Role-specific access to administrative functionality

### 🗄️ Database Management

* MySQL relational database
* Structured schemas for user management
* Transactional booking data
* Inventory and cinema resource tracking
* Relational data management across system components

## 🧱 Tech Stack

| Technology        | Purpose                        |
| ----------------- | ------------------------------ |
| **Java**          | Backend application logic      |
| **Java Servlets** | Server side request handling   |
| **JSP**           | Dynamic web pages and UI       |
| **MySQL**         | Relational database            |
| **HTML/CSS**      | Frontend structure and styling |
| **Apache Tomcat** | Application server             |


## 🚀 Getting Started

### Prerequisites

* **Java JDK**
* **Apache Tomcat**
* **MySQL**
* **Eclipse / IntelliJ IDEA**

### Installation

1. Clone the repository
   
2. Import the project into your preferred Java IDE.
   
3. Configure the MySQL database.

4. Create the required database and import the SQL schema.

5. Update the database credentials in the application's configuration.

6. Configure **Apache Tomcat** as the application server.

7. Deploy and run the application.
